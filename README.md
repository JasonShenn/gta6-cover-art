Sunset Vice Cover Lab turns your own photos into GTA-style multi-panel cover art: upload photos, crop and position each one across the panels, write a bold caption, pick a Vice City sunset or neon grade, and export a share-ready PNG in 1080×1080, 1080×1350 or 1920×1080. Everything runs offline in your browser — photos never leave your machine.

## Run it

```sh
node serve.ts
```
